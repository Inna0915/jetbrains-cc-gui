# GPT-5.6 Codex Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the three concrete GPT-5.6 Codex models, enable `max` reasoning for them end to end, and package plugin version `0.4.7-cyzn`.

**Architecture:** Extend the existing static Codex catalog and translation maps. Add one focused capability set for GPT-5.6 `max` support, use it in the existing reasoning selector, and remove the bridge-level `max` downgrade so the dynamically installed current Codex SDK forwards the value to the CLI.

**Context metadata decision:** The reviewed official sources do not publish a GPT-5.6 context-window value suitable for this repository's context-limit table. Do not add GPT-5.6 context metadata; preserve the existing fallback behavior.

**Tech Stack:** React 19, TypeScript, Vitest/Testing Library, Node.js ESM tests, Java 17/Gradle, IntelliJ Platform Gradle plugin.
